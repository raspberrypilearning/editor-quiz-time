## Add a score

Add a score display to the page header so that the quiz can show the player's points.

```html filename="index.html" line_numbers="true" line_number_start="11" line_highlights="13"
    <header class="header">
      <span class="sitename">Wildlife quiz</span>
      <span id="scoreText" class="sitename">Score: 0</span> <!-- Start the score display at zero. -->
    </header>
```

## Now run your code

Click on **Run**.

You should see **"Score: 0"** in the header next to your quiz title.
